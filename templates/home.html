01. What is a Network?

A network is a group of devices such as computers, phones, servers, and printers connected together so they can share resources and communicate with each other.

02. Types of Networks

LAN

Local Area Network — A network covering a small area, such as a home, school, or office.

WAN

Wide Area Network — A network covering a large geographical area, such as different cities or countries.

MAN

Metropolitan Area Network — A network that generally covers a city or metropolitan area.

03. OSI Model (Open Systems Interconnection)

The OSI model is a conceptual framework created by ISO to standardize how networks communicate. It divides the entire communication process into seven layers. Each layer performs a specific function and communicates with the layer above and below it.

How Data Flows in the OSI Model

When data is sent from one device to another, it travels down through the seven layers on the sender's side. Each layer adds information required for communication. This process is called encapsulation.

L7

Application Layer

This is the layer closest to the end user. It provides network services to applications that communicate over a network.

Example: Email applications such as Gmail or Outlook use network protocols to send and receive messages.

Protocols: HTTP, SMTP, FTP, DNS

Job: Provides network services to end-user applications.

L6

Presentation Layer

Translates data into a format that both the sender and receiver can understand.

Tasks: Encryption, compression, and data formatting.

Example: Data can be formatted, compressed, or encrypted before being sent to the receiver.

L5

Session Layer

Manages communication sessions between two devices. It establishes, maintains, and terminates sessions.

It can also provide checkpoints that help a session resume from a previous point if communication is interrupted.

L4

Transport Layer

Provides end-to-end delivery of data between devices. It determines how data should be transported.

Protocols: TCP provides reliable communication, while UDP provides faster communication with less overhead.

Responsibilities: Uses port numbers, breaks large data into smaller segments, and manages end-to-end communication.

L3

Network Layer

Handles logical addressing and routing. It uses IP addresses to identify source and destination devices and determines how data should travel between networks.

Address: IP address

Device: Router

L2

Data Link Layer

Handles physical addressing using MAC addresses. It organizes data into frames and performs error detection.

Address: MAC address

Devices: Switches and Network Interface Cards (NICs)

L1

Physical Layer

The Physical Layer is responsible for transmitting raw bits through physical media.

Data can be transmitted as electrical signals, light signals, or radio waves.

Examples: Cables, connectors, radio signals, and physical network hardware.

Receiving Side — Reverse Process

When the data reaches the receiving device, it travels upward through the OSI layers. Each layer processes the information intended for it and removes the corresponding header. This reverse process is called de-encapsulation.

04. TCP/IP Model — The Practical Model

The TCP/IP model is the practical networking model used as the foundation of communication on the Internet. It has four layers and is simpler than the seven-layer OSI model.

Why is it called the Practical Model?

TCP/IP focuses on how network communication actually works in real-world networks and on the Internet. The model groups some of the functions that are separated into different layers in the OSI model.

TCP/IP Layer OSI Layers Covered Main Functions Protocols / Examples
Application 5, 6, 7 User applications and data formatting HTTP, HTTPS, SMTP, DNS, FTP
Transport 4 End-to-end communication and reliability TCP, UDP
Internet 3 Routing and logical addressing IP, ICMP, Routing Protocols
Network Access 1 + 2 Physical transmission and MAC addressing Ethernet, Wi-Fi, MAC Addresses

Key Difference: TCP/IP vs OSI

The TCP/IP model is more practical and is used in real-world networking and Internet communication. The OSI model is more theoretical and is commonly used for understanding, learning, and teaching how network communication works.

06. Real-World Example & Security Context

Let's look at how the layers work together when you perform an everyday action, and why attackers target specific layers.

🌐 What happens when you open google.com?

  1. Application Layer: You type google.com in your browser. A DNS request resolves the name to an IP address, and your browser initiates an HTTPS request.
  2. Transport Layer: TCP creates a reliable connection to Google's server using a 3-way handshake (SYN, SYN-ACK, ACK) over port 443.
  3. Internet Layer: The protocol encapsulates the data into packets, adding your IP (source) and Google's IP (destination), deciding the best routing path.
  4. Network Access Layer (Data Link): MAC addresses are added for local delivery to your home router.
  5. Network Access Layer (Physical): Everything is converted into raw electrical or radio signals and blasted over your Wi-Fi or ethernet cable.
  6. Once the data reaches Google's server, the exact reverse process (decapsulation) happens!

🛡️ Why These Models Matter in Cybersecurity

Hackers design attacks targeting specific layers. Security professionals deploy defenses (like firewalls) at specific layers to stop them.

  • Layer 1/2 (Physical/Data Link): MAC Spoofing, ARP Poisoning, physical wiretapping.
  • Layer 3 (Network): IP Spoofing, ICMP Floods (Ping of Death). Standard firewalls filter traffic here.
  • Layer 4 (Transport): TCP SYN Floods (DoS attacks), Port Scanning.
  • Layer 7 (Application): SQL Injection, Cross-Site Scripting (XSS), phishing. Web Application Firewalls (WAF) operate here.

📝 Quick Protocol Reference Note

(Detailed deep-dives into these will be given in later chapters)
HTTP / HTTPS

The foundation of data communication on the web. HTTP is plaintext, while HTTPS uses encryption to keep your browsing secure.

DNS (Domain Name System)

The "phonebook" of the internet. It translates human-readable domain names (like google.com) into machine-readable IP addresses.

FTP (File Transfer Protocol)

A standard network protocol used to transfer computer files between a client and a server on a computer network.

TCP (Transmission Control Protocol)

Provides reliable, ordered, and error-checked delivery of data. It guarantees your data arrives intact (used for web browsing and emails).

UDP (User Datagram Protocol)

Provides fast, connectionless delivery without checking for errors. If a packet drops, it drops (used for live video streaming and gaming).

IPv4 / IPv6

The principal protocols for routing data across network boundaries. IPv4 uses 32-bit addresses, while IPv6 uses 128-bit to solve address exhaustion.
